# Package index

## Diagnostic diagrams

Moment-ratio-style diagrams with bootstrap clouds and concentration
ellipses.

- [`log_cumulant_diagram()`](https://raydonal.github.io/logcumulant/reference/log_cumulant_diagram.md)
  : Log-cumulant diagram
- [`kurtosis_diagram()`](https://raydonal.github.io/logcumulant/reference/kurtosis_diagram.md)
  : Kurtosis-skewness diagram
- [`cv_diagram()`](https://raydonal.github.io/logcumulant/reference/cv_diagram.md)
  : Coefficient-of-variation diagram
- [`three_diagrams()`](https://raydonal.github.io/logcumulant/reference/three_diagrams.md)
  : Combined three-panel diagnostic figure
- [`multi_lc_diagram()`](https://raydonal.github.io/logcumulant/reference/multi_lc_diagram.md)
  : Multi-dataset log-cumulant diagram
- [`plot_lc()`](https://raydonal.github.io/logcumulant/reference/plot_lc.md)
  : Quick log-cumulant plot

## Goodness-of-fit tests

The three nested T-squared statistics and the comparison interface.

- [`T2_one()`](https://raydonal.github.io/logcumulant/reference/T2_one.md)
  : Hotelling-type \\T^2\\ statistic for one cumulant set
- [`T2_all()`](https://raydonal.github.io/logcumulant/reference/T2_all.md)
  : All three nested \\T^2\\ statistics
- [`T2_bootstrap()`](https://raydonal.github.io/logcumulant/reference/T2_bootstrap.md)
  : Parametric bootstrap p-values for the \\T^2\\ statistics
- [`gof_analyze()`](https://raydonal.github.io/logcumulant/reference/gof_analyze.md)
  : Full goodness-of-fit analysis for one distribution
- [`gof_compare_all()`](https://raydonal.github.io/logcumulant/reference/gof_compare_all.md)
  : Compare all candidate distributions
- [`ad_cvm_test()`](https://raydonal.github.io/logcumulant/reference/ad_cvm_test.md)
  : Anderson-Darling and Cramer-von Mises tests
- [`aic_value()`](https://raydonal.github.io/logcumulant/reference/aic_value.md)
  : Akaike information criterion for a fitted family
